Deploy containers on your own cloud

Containr turns a Docker host into a full deployment platform. Git builds, managed databases, previews, failover.

Get started View on GitHub
localhost:3000/canvas

One command, running stack

Requires Docker and openssl. Installs into ./containr, never overwrites your .env.

curl -fsSL https://raw.githubusercontent.com/Dvorinka/Containr/main/install.sh | bash

A control plane, not a pile of YAML

Everything a deployment platform needs, running on hardware you already own. One install, one dashboard.

Visual project canvas

Services appear as nodes on a Railway-style canvas. Drag, group, and wire them together; connections and shared variables are inferred automatically. Start, stop, restart, or roll back with a right-click.

Managed databases

Provision engines from the dashboard, with backups and restore built in.

PostgreSQLMySQLMariaDBMongoDBRedisDragonflyClickHouse

Private networking

Every project gets an isolated Docker network. Services reach each other by name.

web:3000 → ${{service.KEY}}

Git-push deploys

Connect GitHub, GitLab, Bitbucket, or Gitea. Builds, history, and image rollback included.

HA and autoscaling

Failover policies, health checks, node agents, and metric-driven replica scaling.

Admin and audit

Approval console, user management, audit logs, and vulnerability scans behind sign-in.

The whole fleet on one screen

Logs, metrics, builds, and rollbacks without leaving the dashboard. Host telemetry included.

Projects dashboard with host CPU, memory, and disk telemetry.

A catalog worth browsing

Thirty official templates plus community presets. Browse the full catalog or publish your own.
